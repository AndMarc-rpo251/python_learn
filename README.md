# Task Manager

Менеджер задач с графическим интерфейсом на **tkinter** (Python 3.10+, внешних зависимостей нет).

## Запуск

Из папки `TM`:

```bash
python src/interface
```

или из папки `src`:

```bash
python -m interface
```

> Linux: если выдаёт ошибку про tkinter — `sudo apt install python3-tk`.
> Windows и macOS: tkinter входит в стандартный установщик Python.

## Возможности

- **Добавить** задачу (кнопка или `Ctrl+N`): название, описание, статус, приоритет
- **Редактировать** (кнопка, двойной клик или `Enter`)
- **Удалить** (кнопка или `Delete`) с подтверждением
- фильтр по статусу, описание выбранной задачи внизу окна
- автосохранение в `JSON/tasks.json` после каждого действия

В диалоге: `Ctrl+Enter` — сохранить, `Esc` — отмена.

## Тесты

```bash
python -m unittest discover tests
```

План работ — `BACKLOG.md`, известные ошибки — `BAG.md`.

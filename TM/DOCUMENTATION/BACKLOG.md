## 1.0.1 — Оптимизация и модули (2026-11-04)

Новых функций нет, поведение программы то же. Изменилась внутренняя организация.

**Структура**
- Единый файл `interface.py` разбит на модули в папке `src` (как в остальном репозитории):
  - `config.py` — версия, пути, подписи, размеры окна, цвета;
  - `utils.py` — время, сортировка;
  - `core.py` — модель `Task`, проверка данных, `TaskManager`;
  - `storage_file.py` — `JsonStorage` (чтение/запись JSON);
  - `view.py` — окно tkinter (`TaskDialog`, `App`);
  - `interface.py` — точка входа: импортирует функции и классы из модулей и запускает окно.
- Запуск прежний: `python src/interface.py`.
- `TaskManager` больше не создаёт хранилище сам, оно передаётся снаружи — логику можно тестировать без файлов и окна.

**Оптимизация**
- Поиск задачи по id — через словарь (мгновенно), а не перебором списка.
- Таблица очищается одним вызовом вместо цикла.
- Поиск обновляет таблицу не на каждую букву, а через 200 мс после паузы в наборе.
- `Task` использует `slots=True` — меньше памяти, быстрее доступ к полям.
- Проверка данных вынесена в одну функцию `validate()` вместо двух копий кода.
- Два одинаковых выпадающих списка в диалоге строятся одним методом.
- Подсчёт «всего / выполнено» вынесен в `TaskManager.stats()`.

**Тесты**
- Тесты не требуют tkinter: логика полностью отделена от окна. Добавлен тест сортировки (7 тестов).

## 1.0.0 — Финальная версия (2026-11-04)

**Добавлено**
- Поиск по названию и описанию (без учёта регистра), `Ctrl+F` ставит курсор в поле поиска.
- Сортировка по клику на заголовок любого столбца (повторный клик — обратный порядок, стрелка ▲/▼).
- Кнопка **«Готово ✓»**: отмечает задачу выполненной, повторное нажатие возвращает в «К выполнению».
- Подсветка строк: выполненные — серым, высокий приоритет — красным.
- Клавиша `F5` — перечитать данные из файла.
- Переменная окружения `TM_DATA_FILE` — позволяет указать другой путь к файлу данных.
- Поддержка запуска из `.exe`, собранного PyInstaller (папка `JSON` создаётся рядом с `.exe`).
- Версия программы в заголовке окна и в строке состояния.

**Исправлено**
- BAG-001: две запущенные копии программы больше не затирают данные друг друга — перед каждым изменением файл перечитывается.
- Если задача была удалена в другом окне, при правке показывается понятное сообщение вместо ошибки.

**Изменено**
- `Delete` и `Enter` работают только когда фокус в таблице (раньше `Delete` мог сработать при вводе в поле поиска).
- Тесты расширены: поиск, фильтр, работа двух окон одновременно (6 тестов).

## 0.3.0 — Интерфейс изменён: консоль → tkinter (2026-11-03)

- Консольное меню заменено графическим окном на tkinter.
- Таблица задач: ID, название, статус, приоритет, дата изменения.
- Диалог добавления/редактирования: название, описание (многострочное), статус, приоритет.
- Кнопки «Добавить», «Редактировать», «Удалить»; двойной клик по строке открывает редактирование.
- Подтверждение перед удалением.
- Фильтр по статусу, панель с описанием выбранной задачи, строка состояния со счётчиками.
- Горячие клавиши: `Ctrl+N`, `Enter`, `Delete`, в диалоге `Ctrl+Enter` / `Esc`.
- Понятное сообщение, если на Linux не установлен `python3-tk`.
- В `TaskManager.add` добавлен параметр `status`.

## 0.2.0 — Хранение и логика (2026-11-03)

- Модель `Task`: id, название, описание, статус, приоритет, даты создания и изменения.
- Операции: **добавление, редактирование, удаление**, получение списка.
- Хранение в папке `JSON` (файл `JSON/tasks.json`): задачи сохраняются после каждого действия и загружаются при запуске.
- Безопасная запись (через временный файл), повреждённый JSON переименовывается в `tasks.broken.json`, а не теряется.
- Проверка ввода: пустое название, неверный статус и приоритет.
- Идентификаторы не переиспользуются после удаления.
- Консольный интерфейс (меню) и запуск командой `python src/interface`.
- Первые автоматические тесты.

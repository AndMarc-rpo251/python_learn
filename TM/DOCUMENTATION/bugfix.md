# BAG — журнал багов (Bug Tracker)

> Файл назван `BAG.md` по запросу; по смыслу это журнал ошибок (bug report).
> Один баг = одна запись по шаблону ниже. Новые баги добавляй в раздел «Открытые».

## Шаблон записи

```markdown
### BAG-XXX: Краткое название
| Поле | Значение |
|---|---|
| Статус | OPEN / IN PROGRESS / FIXED / WONTFIX |
| Серьёзность | 🔴 Critical / 🟠 Major / 🟡 Minor / 🟢 Trivial |
| Приоритет | высокий / средний / низкий |
| Версия | в которой найден |
| Исправлено в | версия |
| Окружение | ОС, версия Python |
| Дата обнаружения | ГГГГ-ММ-ДД |

**Шаги воспроизведения**
1. ...

**Ожидаемый результат:** ...
**Фактический результат:** ...
**Причина:** ...
**Решение:** ...
```

## Уровни серьёзности

| Уровень | Значение |
|---|---|
| 🔴 Critical | Потеря данных, программа не запускается |
| 🟠 Major | Ключевая функция не работает |
| 🟡 Minor | Неудобство, есть обходной путь |
| 🟢 Trivial | Опечатка, косметика |

## Исправленные / закрытые

### BAG-001: Две копии программы затирали данные друг друга
| Поле | Значение |
|---|---|
| Статус | FIXED |
| Серьёзность | 🟡 Minor |
| Найден в / исправлен в | 0.2.0 / 1.0.0 |

**Шаги:** запустить программу дважды, добавить по задаче в каждой.
**Ожидалось:** обе задачи сохранены. **Было:** оставалась только последняя запись.
**Причина:** каждая копия держала свой список в памяти и перезаписывала файл целиком.
**Решение:** `TaskManager` перечитывает файл перед каждым добавлением, правкой и удалением; клавиша `F5` обновляет экран. Покрыто тестом `test_two_windows_do_not_overwrite_each_other` (в `tests/test_core.py`).

### BAG-002: Ctrl+C / Ctrl+D в консоли давали трассировку
| Поле | Значение |
|---|---|
| Статус | WONTFIX |
| Найден в | 0.2.0 |

**Решение:** неактуален — в 0.3.0 консольное меню заменено окном tkinter; данные сохраняются после каждого действия.

### BAG-003: Повреждённый JSON приводил бы к падению при старте
| Поле | Значение |
|---|---|
| Статус | FIXED |
| Серьёзность | 🟠 Major |
| Найден в / исправлен в | 0.2.0 / 0.2.0 |

**Шаги:** записать в `JSON/tasks.json` некорректный текст и запустить программу.
**Решение:** `JsonStorage.load()` переименовывает файл в `tasks.broken.json` и начинает с пустого списка. Покрыто тестом `test_broken_json`.

### BAG-004: На Linux нет tkinter — непонятная ошибка при запуске
| Поле | Значение |
|---|---|
| Статус | FIXED |
| Найден в / исправлен в | 0.3.0 / 0.3.0 |

**Причина:** на Linux tkinter ставится отдельно от Python.
**Решение:** при `ImportError` выводится подсказка `sudo apt install python3-tk`.

### BAG-005: `Delete` в поле поиска удалял бы выбранную задачу
| Поле | Значение |
|---|---|
| Статус | FIXED |
| Найден в / исправлен в | 1.0.0 (при разработке) / 1.0.0 |

**Причина:** горячая клавиша была привязана ко всему окну.
**Решение:** `Delete` и `Enter` привязаны только к таблице.
